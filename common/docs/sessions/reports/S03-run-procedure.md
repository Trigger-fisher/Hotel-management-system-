2. Message Web UI 1 and Mobile UI 1 (START): read docs/sessions/reports/S03-dashboards.md, especially FRONTEND ARCHITECTURE RULES (top-level Next.js features, optimise, ONE internal component library reused everywhere, docs/COMPONENTS.md). Then the Hotel areas in order. Continue from where you stopped. 3-line status after each step.
3. Message hms-7e (START): first research current Next.js best practices (official docs and release notes for the installed version), write docs/design/ui-review/12-NEXTJS-PERFORMANCE-AND-COMPONENTS.md, then audit the web app for efficiency, optimisation and component reuse, and review Guest and Corporate against docs/design/ui-review/10-DASHBOARD-DESIGN-SPEC.md and the Pallav portal design, day and night. If ALL UI work in S03-dashboards.md is not finished (Guest, Corporate, every Hotel area, login connected, web and mobile), schedule ONE more run 5 hours later with CronCreate (one-shot, minute not 0 or 30, prompt: "Follow docs/sessions/reports/S03-run-procedure.md").
