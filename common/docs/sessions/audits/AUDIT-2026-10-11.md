## How a layer is scored
| Layer | done | partial | none |
|---|---|---|---|
| Database | tables and repos for the whole module exist | some tables missing | no tables |
| Server | routes + services for the whole module | some routes missing | no routes |
| Screens | every screen of the module exists (on mock data is enough) | some screens or states missing | no screens |
| Wiring | the real adapter exists **and** a checklist/doc says it was tested live (`?api=real`) | adapter exists, not recorded as tested live, or part of its calls answer "not yet" | no adapter |

A layer's percentage = (done + 0.5 x partial) / modules scored. `unknown` is left out. The project percentage is the plain mean of the four layers.
