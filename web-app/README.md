# web-app

The HMS Next.js app (screens, server and API). See the repository `README.md` for the layout and how to run it, and `docs/PROJECT-STATE.md`, `docs/UI.md`, `docs/BACKEND.md` for the details.

```bash
npm run dev   # http://localhost:3000 = website, /login = sign-in (test mode by default; /login?api=real for the database)
```
